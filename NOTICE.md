# Provenance

The Python probe, metadata collector, offline tests, documentation, and authored sandbox/fake-HID fixtures were produced during this investigation and are released under [the Unlicense](LICENSE). The license text was copied unchanged from [the template selected by the repository owner](https://raw.githubusercontent.com/licenses/license-templates/refs/heads/master/templates/unlicense.txt).

`analysis/android/sources/` contains selected reconstructed Java from Logitech's Android application and its included libraries. These are analysis artifacts, not the original source project, a complete build, or a new license grant. The Unlicense applies to newly authored work, not to third-party code or underlying vendor material. Package names identify their original owners. The original APK, embedded API keys and analytics identifiers, and the complete application/dependency tree are not distributed here.

String-offset files and inventories derive from the original Logitech diagnostic packages. The REA JSON is a redacted analysis export. Original artifact and source-file hashes identify the unmodified inputs; hashes of redacted archive files are recorded separately.

The original application, runtime, tool archives, PDFs, and firmware are not included. Source URLs and hashes are provided for independent acquisition. The hash of a raw private log is evidence of the acquired file's identity, not permission to disclose its contents.
